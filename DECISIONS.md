
## Why Django?
- Fast backend development
- Built-in admin panel
- Easy ORM for database handling
- Good support for REST APIs

---

## Why React?
- Dynamic UI updates
- Component-based structure
- Efficient rendering of table data

---

## Why REST API?
- Simple communication between frontend and backend
- Easy integration with React

---

## Why CSV ingestion?
- Real-world ESG systems receive data from CSV exports
- Easy simulation of SAP / utility systems

---

## Assumptions
- SAP, Utility, and Travel data are simulated using CSV/JSON
- No real external APIs were integrated
- Authentication was not implemented for simplicity

---

## Data Flow
CSV → Django ingestion → Database → REST API → React Dashboard
